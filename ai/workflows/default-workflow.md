# Default Workflow

## 기본 원칙

- 변경은 요청 범위 안에서 최소한으로 수행한다.
- 파괴적이거나 되돌리기 어려운 작업은 사용자 확인 후 진행한다.
- 코드와 문서가 어긋나면 관련 문서를 함께 갱신한다.
- 세션이 바뀌어도 이어질 수 있도록 의도, 영향 범위, 검증 결과를 남긴다.

## 기본 흐름

1. 요청 의도와 범위를 확인한다.
2. 현재 저장소 구조와 관련 문서를 먼저 읽는다.
3. 필요한 skill이 있으면 사용하고, 없으면 기본 workflow로 진행한다.
4. 작업 분류를 정한다.
5. 구현 또는 문서 변경을 수행한다.
6. 검증 결과와 남은 리스크를 정리한다.
