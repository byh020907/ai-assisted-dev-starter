# Project Context

이 디렉토리는 현재 프로젝트 전체에 적용되는 상위 문서를 둔다.

- `brief.md`: 프로젝트 개요
- `ai-collaboration.md`: 프로젝트별 AI 협업 규칙

## 권장 읽기 순서

1. `brief.md`
2. `ai-collaboration.md`

## 문서 역할

- `brief.md`는 프로젝트의 배경, 목표, 범위, 제약을 먼저 이해하기 위한 기본 문서다.
- `ai-collaboration.md`는 응답 언어, 협업 방식, 프로젝트 전용 예외 규칙처럼 세션 간 일관성이 필요한 로컬 규칙을 둔다.

## 생성 메모

- 실제 `consumer`에서는 `brief.md`만 먼저 존재할 수 있다.
- `ai-collaboration.md`가 아직 없으면 이 디렉토리의 템플릿을 기준으로 새로 만든다.
