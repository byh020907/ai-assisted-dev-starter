# AI Starter Context

이 디렉토리는 `consumer`의 로컬 컨텍스트를 관리한다.

- `project/`: 프로젝트 개요, 정책, AI 협업 규칙
- `tasks/`: 작업 단위 문서 묶음
- `adr/`: 장기 구조 결정 기록

## 먼저 볼 문서

- `project/README.md`: 프로젝트 상위 문서 인덱스
- `project/brief.md`: 현재 프로젝트의 목적, 범위, 성공 기준
- `project/ai-collaboration.md`: 현재 프로젝트에서만 적용하는 AI 협업 규칙

## 주의

- 실제 프로젝트에는 이 구조의 일부만 먼저 생성될 수 있다.
- 특정 문서가 없더라도 구조가 잘못된 것은 아니며, 필요한 시점에 템플릿 기준으로 추가한다.
