# Project Template

이 디렉토리는 `consumer`에 생성할 로컬 구조의 템플릿 원본을 둔다.

기본 루트는 `.ai-assisted-dev-starter/`를 기준으로 작성되어 있으며,
초기화 스크립트는 이 구조를 참고해 필요한 파일만 생성한다.

## 탐색 시작점

- `.ai-assisted-dev-starter/README.md`: 로컬 리소스 전체 인덱스
- `.ai-assisted-dev-starter/project/README.md`: 프로젝트 상위 문서 인덱스
- `.ai-assisted-dev-starter/project/brief.md`: 프로젝트 개요 기본 문서
- `.ai-assisted-dev-starter/project/ai-collaboration.md`: 프로젝트별 AI 협업 규칙

## 생성 원칙

- 실제 `consumer`에는 필요한 파일만 생성될 수 있다.
- 따라서 어떤 프로젝트에서는 `brief.md`만 먼저 있고 `ai-collaboration.md`는 아직 없을 수 있다.
- 문서를 찾을 때는 먼저 각 디렉토리의 `README.md`를 인덱스로 보고, 없는 문서는 필요 시 템플릿 기준으로 생성한다.
