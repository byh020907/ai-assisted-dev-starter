# Task

## 작업명

- Git 이력 제목과 커밋 메시지 기본 포맷 추가

## 배경

- 현재 저장소는 커밋 지원 workflow는 있으나, 이력 제목과 커밋 메시지의 기본 포맷은 명시하지 않고 있다.
- 이 때문에 새 대화나 새 세션마다 이력 작성 방식이 달라질 수 있다.
- staged diff 기준으로 이력 내용까지 함께 제안해야 검토 흐름이 완결된다.
- 이력 내용을 제안할 때 표현 방식이 정해져 있지 않으면 응답 형식이 다시 흔들릴 수 있다.
- 이력 제목도 일반 문장으로 제안되면 복사가 불편할 수 있다.
- 이력번호 확정 전에 AI가 번호를 임의로 채우면 사용자 책임 범위를 침범하게 된다.

## 목표

- 이력 제목과 커밋 메시지의 기본 포맷을 workflow와 예시 문서에 명시한다.
- 이력 번호와 제목의 관계를 일관되게 유지할 수 있게 한다.
- 이력 내용도 staged diff 기준으로 함께 제안하는 흐름을 문서화한다.
- 이력 제목과 이력 내용은 사용자에게 코드 블록으로 제안하는 표현 규칙을 추가한다.
- 이력번호는 사용자 확정 전까지 자리표시자로만 제안하는 규칙을 추가한다.
