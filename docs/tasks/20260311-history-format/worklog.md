# Worklog

## 2026-03-11

### 오늘 작업

- Git commit workflow에 이력 제목, 이력 내용, 커밋 메시지, 브랜치 이름의 기본 포맷을 추가했다.
- 사람용 시나리오 예시를 새 포맷 기준으로 갱신했다.
- 관련 ADR에 포맷 기준을 보강했다.
- 브랜치 분류 접두어를 제거하고 단일 브랜치 포맷으로 정리했다.
- staged diff 기준으로 이력 내용도 함께 제안하는 흐름을 반영했다.
- 이력 제목도 코드 블록으로 제안하도록 표현 규칙을 보강했다.
- 이력 내용은 코드 블록으로 제안하는 표현 규칙을 추가했다.
- 이력번호는 사용자 확정 전까지 임의로 채우지 않고 자리표시자로만 제안하도록 정리했다.

### 확인한 내용

- 기존 문서에는 이력 번호와 메시지를 사용한다는 흐름만 있고 형식 자체는 비어 있었다.
- 예시 문서의 포맷은 규칙이 아니라 예시에 머물러 있어 세션마다 다른 초안이 나올 수 있었다.
- 브랜치 이름 규칙도 예시는 있었지만 기본 포맷은 명시돼 있지 않았다.
- 이력 제목만 있고 이력 내용 제안 규칙이 없어 실제 검토 흐름이 한 단계 비어 있었다.
- 이력 제목은 일반 문장으로 보이면 복사하기 불편할 수 있었다.
- 이력 내용 표시 형식이 없으면 새 대화에서 bullet, 문단, 표 등이 섞일 수 있다.
- 이력번호를 AI가 임의로 채우면 사용자 검토 이전에 잘못된 커밋/브랜치 초안이 굳어질 수 있다.

### 결정 / 보류

- 결정:
- 이력 제목은 `[주제 or 카테고리] 제목` 형식으로 통일한다.
- 이력 제목은 사용자에게 코드 블록으로 제안한다.
- 이력 내용은 staged diff 기준 핵심 변경 bullet 요약으로 제안한다.
- 이력 내용은 사용자에게 코드 블록으로 제안한다.
- 커밋 제목은 `[#이력번호] 이력번호에 해당하는 제목과 동일` 형식으로 통일한다.
- 브랜치 이름은 `이력번호-이력제목 영문 소문자 slug` 형식으로 통일한다.
- 브랜치 분류용 접두어는 사용하지 않는다.
- 이력번호는 사용자 확정 전까지 AI가 임의로 채우지 않는다.
- 보류:
- 카테고리 집합과 한글 제목의 영문 변환 규칙 세부 목록은 필요 시 프로젝트별로 보강한다.
