# Tasks Docs

이 디렉토리는 작업 단위 문서를 관리하는 기본 위치다.

기본 원칙:

- 하나의 task는 하나의 디렉토리로 관리한다.
- 관련 문서는 가능한 한 같은 task 디렉토리에 함께 둔다.
- 디렉토리 이름은 `20260311-archive-note` 같은 `YYYYMMDD-slug` 형식을 사용한다.
- 기존 실문서는 과거 형식을 유지할 수 있지만, 새로 만들거나 업데이트되는 task 문서 묶음은 최신 템플릿 기준을 따른다.

예시 구조:

```text
+docs/tasks/20260311-archive-note/
+|-- task.md
+|-- worklog.md
+`-- decision.md
```
