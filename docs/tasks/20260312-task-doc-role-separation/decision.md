# 결정 기록

## 결정 정보

- 제목: task 문서 3종 역할 분리와 decision 템플릿 한글화
- 날짜: 2026-03-12
- 상태: accepted

## 배경

- 현재 템플릿은 세 문서를 나누고 있지만 일부 섹션이 다른 문서 역할과 겹쳐 실제 사용 시 경계가 흐려질 수 있었다.
- 또한 `decision` 템플릿은 소제목 일부가 영어로 남아 있어 한국어 문서 흐름과 통일되지 않았다.

## 검토한 선택지

1. 기존 템플릿을 유지하고 작성 가이드만 보강한다.
2. 템플릿 자체를 수정해 문서 역할이 섹션 구조에 바로 드러나게 만든다.
3. 문서 수를 줄여 `task`와 `decision`을 합친다.

## 결정

- 옵션 2를 채택한다.
- `task.md`는 최종 정의 문서답게 메모성 섹션을 제거한다.
- `worklog.md`는 결정 섹션을 제거하고 작업 기록 중심으로 정리한다.
- `decision.md`는 한국어 소제목으로 통일하고 결정 근거 문서 역할에 맞는 구조만 남긴다.

## 영향

- 장점:
- 문서 이름과 섹션만 봐도 각 파일의 역할이 더 분명해진다.
- task 진행 기록과 진행 방향 결정 근거가 섞이는 일을 줄일 수 있다.
- 단점:
- 기존 task 실문서는 새 구조와 다르게 보일 수 있어 해석 기준을 한 번 더 맞춰야 한다.
