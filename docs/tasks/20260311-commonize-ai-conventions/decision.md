# Decision Log

## Decision

- 제목: Cursor 초안 중 범용 규칙만 AI 공통 관례로 승격
- 날짜: 2026-03-11
- 상태: accepted

## Context

- 사람용 Cursor 활용 초안에는 AI 협업 방식에 대한 여러 규칙이 포함돼 있었다.
- 이 저장소는 사람용 설명과 AI 실행 기준을 분리하며, 특정 도구 종속 내용은 가능한 한 독립 문서로 분리한다.
- 따라서 초안 전체를 공통 기준으로 넣기보다 범용 규칙만 선별할 필요가 있었다.

## Options Considered

1. 초안 내용을 거의 그대로 공통 규칙으로 반영한다.
2. 범용성이 높은 항목만 `ai/standards/conventions.md`에 반영한다.
3. 공통 규칙 반영 없이 사람용 예시 문서로만 보존한다.

## Decision

- 옵션 2를 채택한다.
- 이번에는 모호한 요청을 선택지로 좁혀가는 방식, 기술 스택 우선 확인, Mermaid 우선 사용만 공통 관례로 반영한다.

## Consequences

- 장점:
- 다양한 도구와 프로젝트에 공통 적용 가능한 규칙만 남겨 재사용성이 높아진다.
- `conventions.md`의 성격과 저장소 분리 원칙을 유지할 수 있다.
- 단점:
- 사람용 발표 초안의 실전 감각과 사례성은 공통 기준 문서에 직접 남지 않는다.
- 후속 작업:
- 필요 시 사람용 예시 문서에서 활용 사례를 별도로 정리한다.
