# Task

## 작업명

- 프로젝트별 AI 옵션 규칙 문서 위치와 예시 구조 추가

## 배경

- 공통 규칙으로 올리기엔 강도가 높은 AI 협업 스타일 항목들이 있다.
- 현재 저장소에는 이런 프로젝트별 옵션을 어디에 두는지 명확히 안내하는 문서가 부족하다.

## 목표

- 프로젝트별 AI 협업 스타일을 둘 문서 위치를 구조에 반영한다.
- 사람과 AI 모두가 공통 규칙과 프로젝트 규칙의 경계를 이해할 수 있게 한다.
