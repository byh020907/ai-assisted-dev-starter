# Docs

이 디렉토리는 사람이 읽고 관리하는 운영 문서와 프로젝트 산출물을 모아두는 공간이다.

## 구성 원칙

- 프로젝트 전체를 설명하는 상위 문서는 `project/`에 둔다.
- 개별 작업 단위 문서는 `tasks/` 아래에 둔다.
- 중요한 구조적 결정은 `adr/`에 기록한다.
- 하나의 task에 관련된 문서는 가능한 한 `docs/tasks/<date>-<task-slug>/` 아래에 함께 둔다.
- 이 디렉토리는 현재 프로젝트에서 축적되는 실문서를 관리하는 위치로 본다.
- AI 전용 기준, workflow, 템플릿, 시나리오 같은 참조 자산은 `ai/`에서 관리한다.

## 추천 운영 방식

- 프로젝트 전반 배경과 요구사항은 `project/`에서 관리한다.
- 작업 진행 중 생기는 기록은 `tasks/`에서 관리한다.
- 장기 기준이 되는 결정은 `adr/`에 남긴다.
