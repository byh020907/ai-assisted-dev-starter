# ADR 0001: Use `skills` Instead of `prompts` Under `ai/`

- Status: accepted
- Date: 2026-03-11

## Context

이 저장소는 사람용 문서와 AI용 문서를 분리하기 위해 루트 아래 `ai/` 디렉토리를 도입했다.
초기 구조를 정리하는 과정에서 AI 전용 재사용 단위를 `prompts/`로 둘지 `skills/`로 둘지 선택이 필요했다.

`prompt`는 개별 요청 문구나 예시 문장을 의미하는 경우가 많아 범위가 좁고 모호하게 읽힐 수 있다.
반면 이 저장소에서 관리하려는 대상은 단순 문구보다, 반복 가능한 작업 단위와 사용 조건, 입력과 출력 기대치, 적용 시점을 함께 포함하는 형태에 가깝다.

## Options Considered

1. `ai/prompts/`를 유지한다.
2. `ai/skills/`로 변경한다.
3. 둘 다 두고 혼용한다.

## Decision

`ai/prompts/` 대신 `ai/skills/`를 사용한다.

이 저장소에서는 재사용 자산을 단순 프롬프트 모음이 아니라 작업 목적과 사용 규칙을 포함한 단위로 관리한다.
따라서 폴더 이름도 그 의도를 더 잘 드러내는 `skills`를 기본 용어로 채택한다.

## Consequences

- Positive:
  - 재사용 자산의 성격이 더 명확해진다.
  - 단순 문장 모음이 아니라 작업 단위라는 인식이 강화된다.
  - 향후 skill 단위 문서를 확장할 때 구조적 일관성이 좋아진다.
- Negative:
  - `prompt`라는 익숙한 표현에 비해 처음엔 다소 무겁게 느껴질 수 있다.
  - 프로젝트에 따라 실제 내용이 단순 프롬프트 수준일 경우 이름이 과하게 느껴질 수 있다.
- Follow-up:
  - `ai/README.md`와 `AGENTS.md`는 이 결정을 전제로 참조 구조만 설명한다.
  - 이후 실제 재사용 단위를 추가할 때 `skills` 형식에 맞는 템플릿을 보강한다.
