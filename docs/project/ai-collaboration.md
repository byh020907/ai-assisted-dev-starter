# AI Collaboration

이 문서는 이 프로젝트에서만 적용하는 AI 협업 스타일과 옵션 규칙을 정리한다.

여기에 두는 내용은 모든 프로젝트에 공통으로 적용하기보다,
팀의 선호나 협업 방식에 따라 달라질 수 있는 항목을 우선한다.

## 목적

- 팀이 선호하는 AI 협업 방식을 프로젝트 문서로 명시한다.
- 공통 규칙과 프로젝트별 옵션을 분리해 유지보수성을 높인다.
- 새 대화나 새 세션에서도 같은 협업 스타일을 재사용하기 쉽게 한다.

## 권장 항목 예시

### 응답 언어

- 기본 응답 언어를 한국어로 유지한다.
- 코드, 명령어, 라이브러리 고유 명칭은 원문 표기를 유지할 수 있다.

### 구현 전 제안 방식

- 요구사항이 바로 구현으로 이어지기 어려우면 방법이나 선택지를 먼저 제안한다.
- 선택지 간 영향 차이가 작지 않으면, 구현 전에 어떤 방향으로 갈지 먼저 합의한다.

### 코드 변경 설명 방식

- 모든 코드에 기계적으로 주석을 추가하지는 않는다.
- 다만 의도 파악이 어려운 변경, 정책 변화, 복잡한 예외 처리에는 짧은 요약 주석이나 문서 기록을 남기는 것을 권장한다.

## 공통 규칙과의 경계

- 여러 프로젝트에 공통 적용 가능한 규칙은 `ai/standards/` 또는 `ai/workflows/`에 둔다.
- 이 프로젝트에서만 유효한 선호, 톤, 협업 스타일은 이 문서에서 관리한다.
- 공통 규칙으로 승격할 만큼 반복되면 이후 `ai/standards/conventions.md` 반영 후보로 검토한다.
