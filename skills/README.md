# AI Skills

이 디렉토리는 반복적으로 재사용할 작업 단위와 사용 가이드를 두기 위한 공간이다.

현재는 구체 skill 문서보다 구조만 먼저 잡아둔 상태다.
실제 반복 작업 단위가 안정되면 이 디렉토리에 개별 skill 문서를 추가한다.

예상되는 후보 예시:

- 코드 리뷰 진행
- 기능 명세 초안 작성
- 버그 재현 정보 정리
- 릴리즈 전 검증

## skill로 보는 이유

- 단순 프롬프트 문구보다 작업 목적과 사용 조건을 함께 담기 쉽다.
- 같은 요청이라도 입력, 출력, 확인 순서를 같이 정의할 수 있다.
- 프로젝트가 커질수록 재사용성과 유지보수성이 더 좋아진다.
